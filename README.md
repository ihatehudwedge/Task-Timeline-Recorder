# 작업 타임라인 통합 관리 시스템 기능명세서

## 1. 프로젝트 개요
* **추진 배경:** 기존 작업 진행 상황 및 시간대별 기록이 메신저로만 공유되어 이력이 파편화되고 휘발되는 문제가 발생함.
* **시스템 목표:** 별도의 웹 서버 구축 없이 오프라인(폐쇄망) 및 로컬 공유 폴더 환경에서 즉시 구동되며, 여러 작업자가 작업 카드와 시간대별 타임라인을 통합 관리할 수 있는 프로그램 구현.

---

## 2. 시스템 환경 및 아키텍처
### 2.1 구동 환경 (완전 오프라인 지원)
* **No-Server (Serverless):** 별도의 백엔드 웹 서버나 DB 엔진 설치 없이 브라우저(Chrome, Edge 등)에서 `index.html`을 직접 실행하여 구동.
* **Zero-CDN (폐쇄망 대응):** 인터넷이 차단된 환경에서 폰트나 아이콘이 깨지지 않도록 외부 CDN 라이브러리를 일체 배제하고, OS 기본 시스템 폰트(`Malgun Gothic`, `맑은 고딕`, `Segoe UI` 등) 및 인라인 SVG 아이콘만 사용.

### 2.2 소스 파일 구조 (3파일 분리)
유지보수 및 역할 분리를 위해 동일 경로 내 3개의 파일로 구성함.
* **`index.html`:** 전체 레이아웃, 상단 제어 바, 검색/필터 툴바, 좌측 슬라이드 수정 탭(Drawer), 메인 카드 그리드 및 토스트 알림 영역 마크업 정의 (UI 상에서 'JSON' 용어를 배제하고 모두 '카드'로 통일).
* **`style.css`:** Jira 다크 모드 레퍼런스 기반의 컬러 팔레트, 상태별(4단계) 색상 테마, 드로어 슬라이드 애니메이션, 타임라인 스트림 UI 및 반응형 그리드 스타일 정의.
* **`app.js`:** 공유 폴더 디렉터리 연동(`File System Access API`), 카드별 파일 파편화 입출력, 타임라인 충돌 방지 병합(Smart Merge) 로직, 원클릭 템플릿(7종) 및 인라인 상태 변경 로직 구현.

## 3. 데이터 저장 및 동시 작업 제어 (카드별 파편화 구조)
### 3.1 카드 단위 개별 파일 파편화 저장
* 단일 파일에 전체 데이터를 통째로 저장할 때 발생하는 동시 덮어쓰기 충돌을 방지하기 위해, **공유 폴더 내에 카드별로 개별 파일(예: `TASK-101.json`, `TASK-102.json`)을 생성하여 파편화 저장**함 (파일명 내 특수문자는 `_`로 자동 치환하여 안전하게 저장).
* 최초 실행 시 불필요한 샘플 데이터를 배제하고 빈 보드 상태에서 시작함.

### 3.2 공유 폴더 연동 및 충돌 방지 병합 (Smart Merge)
* **공유 카드 폴더 연결 (`showDirectoryPicker` API):** 상단의 `[공유 카드 폴더 연결]` 버튼을 통해 로컬 또는 네트워크 공유 폴더를 한 번 지정하면 폴더 내 모든 카드 파일(`.json`, `.card`)을 자동으로 스캔하여 최근 수정일(`updatedAt`) 역순으로 보드에 표시. (단일 카드 객체 파일뿐만 아니라 `cards` 배열을 포함한 묶음 파일 포맷도 호환 로드 지원)
* **동시 수정 병합 및 삭제 이력 보호:**
  * 서로 다른 카드를 작업할 때는 파일 자체가 분리되어 있어 충돌이 발생하지 않음.
  * 만약 두 작업자가 **동일한 카드**를 동시에 수정하여 저장하더라도, 저장 직전에 디스크의 해당 카드 파일을 먼저 읽어 타임라인 기록(ID 기준)을 자동 병합(Merge)한 뒤 최신순으로 정렬하여 덮어씀.
  * 이때 현재 수정 세션에서 사용자가 명시적으로 삭제하거나 수정한 타임라인 ID(`removedTimelineIdsInSession`)를 추적하여, 병합 과정에서 삭제된 기록이 다시 복원되는 현상을 방지함.
* **폴백(Fallback) 및 캐시 지원:** 폴더 직접 연결 API를 지원하지 않는 브라우저 환경을 위한 `[카드 파일 불러오기]`(다중 파일 선택 Upsert) 기능 및 브라우저 `localStorage`(`TASK_TIMELINE_FRAGMENTED_CACHE_V2`) 임시 캐시 자동 저장 지원.

## 4. 상세 기능 명세

### 4.1 상단 헤더 및 제어 바
| 버튼 / 요소명 | 기능 설명 |
| :--- | :--- |
| **폴더 연결 상태 배지** | 현재 공유 카드 폴더 연결 여부(로컬 임시 모드 / 연결된 폴더명) 및 상태 표시등(초록색 점)을 실시간으로 표시 |
| **공유 카드 폴더 연결** | 로컬 또는 네트워크 공유 폴더를 선택하여 카드별 개별 파일 읽기/쓰기 권한 연결 |
| **카드 파일 불러오기** | 파일 탐색기에서 파편화된 개별 카드 파일(`.json`, `.card`)들을 다중 선택하여 보드로 즉시 병합 로드 |
| **카드 목록 새로고침** | 연결된 공유 폴더에서 다른 작업자가 추가/수정한 최신 카드 파일들을 다시 스캔하여 화면 갱신 (현재 열려있는 수정 탭이 있을 경우 탭 내용도 최신 데이터로 동기화) |
| **새 카드 등록** | 페이지 이동 없이 좌측에서 새 카드 작성 탭(Drawer)을 오픈 |

### 4.2 검색 및 필터 툴바
* **통합 키워드 검색:** 작업명, 카드 ID, 담당 작업자, 카드 작성자, 타임라인 메모 내용(작성자·내용·시간)을 대소문자 구분 없이 실시간으로 통합 검색.
* **작업 현황 필터:** `전체` / `대기` / `진행` / `이슈발생` / `종료` 상태별 원클릭 필터링.
* **담당 작업자 필터:** 현재 등록된 카드들의 작업자 목록을 중복 없이 자동 추출(가나다순 정렬)하여 전체 인원수와 함께 드롭다운 필터로 제공.
* **상태별 카운트 요약:** 툴바 우측 영역에 전체 카드 수 및 4단계 상태별 카드 개수를 상태별 포인트 컬러와 함께 실시간 집계하여 표시.

### 4.3 메인 카드 보드 및 인라인 상태 변경
* **카드 표시 정보:**
  * 카드 고유 번호 (`TASK-101`부터 최대 번호 기준 자동 채번) 및 작업명
  * 담당 작업자(실무자) 및 카드 작성자(최초 기록자), 누적 로그 건수 표시
  * 시간순(최신순)으로 정렬된 타임라인 메모 스트림 (최대 높이 250px 스크롤, 최신 항목 파란색 포인트 강조)
  * 최근 수정 일시(`updatedAt`) 및 매핑된 개별 카드 파일명 표시
  * 현재 좌측 수정 탭에서 편집 중인 카드는 파란색 외곽선(`active-editing`)으로 하이라이트 표시
* **인라인 상태 즉시 변경 (수정 탭 오픈 불필요):**
  * 각 카드 우측 상단에 배치된 상태 드롭다운(`대기` / `진행` / `이슈발생` / `종료`)을 클릭하여 **수정 버튼을 누르지 않고도 카드 위에서 즉시 작업 현황을 변경**할 수 있음.
  * 상태 변경 시 카드 좌측 테두리 및 드롭다운 배지 색상이 즉시 바뀌고 수정 일시가 갱신되며, 연결된 공유 폴더의 해당 카드 파일에 즉시 저장됨 (좌측 수정 탭에 해당 카드가 열려 있을 경우 탭 내부의 상태 선택 버튼도 자동 동기화).

### 4.4 좌측 슬라이드 수정 탭 (Left Drawer)
카드의 `[✎ 수정]` 버튼 또는 상단 `[새 카드 등록]` 클릭 시, 페이지 이동 없이 화면 왼쪽에서 슬라이드 탭(폭 480px)이 열리며 우측 카드 보드와 동시에 표시됨.
* **기본 메타데이터 편집:** 작업명(필수 입력 검증), 작업 현황(4단계 선택 버튼), 담당 작업자, 카드 작성자 입력 및 수정.
* **타임라인 직접 입력 및 빠른 시간 설정:**
  * 타임라인 시간은 `YYYY-MM-DD HH:MM` 포맷으로 직접 타이핑하여 수정 가능하며, 탭 오픈 시 현재 시각으로 자동 세팅됨.
  * `[지금 시간]`, `[-5분]`, `[-10분]`, `[-30분]`, `[-1시간]` 원클릭 시간 조정 칩을 제공하여 과거 메신저 기록을 소급 입력할 때 편의성 확보.
  * 메모 작성자 입력란은 카드 수정 시 해당 카드의 `담당 작업자`(없으면 `카드 작성자`) 이름으로 자동 기본 세팅되며, 비워둘 경우 `담당 작업자 → 카드 작성자 → "담당자"` 순으로 자동 기입됨.
  * 메모 입력창에서 **`Ctrl + Enter`** 단축키를 누르면 버튼 클릭 없이 즉시 타임라인 목록에 추가됨.
* **원클릭 작업 문구 템플릿 (7종):**
  * 자주 사용하는 작업 기록 문구 7종(`🚀 작업착수`, `✅ 서비스 체크`, `📢 유관공유`, `⚠️ 이슈발생`, `🔎 원인분석`, `🔄 롤백/보류`, `🏁 작업종료`)을 칩 버튼으로 제공하여 클릭만으로 입력창에 즉시 삽입 (기존 입력 내용이 있을 경우 줄바꿈 후 하단에 이어서 추가).
  * `app.js` 최상단 `TIMELINE_TEMPLATES` 배열을 수정하여 손쉽게 커스텀 템플릿 추가/변경 가능.
* **누적 타임라인 개별 관리:**
  * 해당 카드에 등록된 타임라인 메모들을 최신순으로 확인.
  * 개별 메모의 `[수정]` 클릭 시 해당 시간, 작성자, 내용이 상단 입력창으로 다시 불러와지며 목록에서 임시 추출되어 재편집 가능.
  * 개별 메모의 `[삭제]` 클릭 시 해당 타임라인 항목 즉시 제거.
* **카드 저장 및 삭제:**
  * `[카드 저장]` 클릭 시 만약 타임라인 메모 입력창에 작성 중이던 텍스트가 남아있다면 누락되지 않도록 자동으로 타임라인에 먼저 추가한 뒤, 해당 카드 파일만 단독 갱신 저장함.
  * `[카드 삭제]` 클릭 시 확인 대화상자(`confirm`)를 거쳐 보드 및 공유 폴더에서 해당 카드 파일을 완전히 삭제함 (신규 등록 모드에서는 삭제 버튼 숨김 처리).

### 4.5 토스트 알림 (Toast Notification)
* 우측 하단에 작업 결과(폴더 연결 성공, 카드 저장/삭제 완료, 입력값 누락 경고, 오류 안내 등)를 보여주는 토스트 메시지가 생성되며 약 2.8초 후 페이드아웃 효과와 함께 자동 소멸함.

## 6. 개별 카드 파일 데이터 스키마 (`TASK-XXX.json`)
공유 폴더 내에 카드 단위로 생성되는 개별 파일의 데이터 구조는 다음과 같음.

```json
{
  "id": "TASK-101",
  "title": "작업명 텍스트",
  "status": "진행",
  "worker": "홍길동",
  "author": "김철수",
  "updatedAt": "2026-10-13 13:30",
  "timeline": [
    {
      "id": "TL-1760330000000-123",
      "time": "2026-10-13 13:30",
      "author": "홍길동",
      "content": "[서비스 체크] 서비스 정상 동작 확인 (특이사항 없음)"
    }
  ]
}
